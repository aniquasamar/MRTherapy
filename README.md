# MRTherapy — Therapy Practice Website

MrTherapy is a responsive frontend website for a fictional therapy practice. Built with Next.js, React, and TypeScript, the project focuses on reusable UI components, page layout, styling, and a consistent user experience across screen sizes.

**[Live Demo](https://mrtherapy.vercel.app/) · [GitHub Repository](https://github.com/aniquasamar/MrTherapy)**

## Features

- **Responsive Design:** Adapt page layouts for desktop and mobile screens.
- **Reusable Components:** Organize the interface into reusable React components.
- **Consistent UI Styling:** Customize typography, imagery, spacing, and visual elements.
- **Multi-Page Interface:** Structure website content into clear, navigable sections.
- **Modern Frontend Stack:** Use Next.js, React, and TypeScript to build the user interface.

## Tech Stack

**Framework:** Next.js

**Frontend:** React, TypeScript

**Styling:** Tailwind CSS

**Tools:** Git, GitHub
